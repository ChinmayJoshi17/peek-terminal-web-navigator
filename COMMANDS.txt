1. ENVIRONMENT SETUP
--------------------------------------------------------------------------------
Open a terminal in the project directory (PowerShell or Command Prompt):

# Create a virtual environment (recommended)
python -m venv .venv

# Activate the virtual environment:
# - On PowerShell:
.\.venv\Scripts\Activate.ps1
# - On Windows CMD:
.\.venv\Scripts\activate.bat
# - On Linux / macOS:
source .venv/bin/activate

# Install required Python dependencies
pip install -r requirements.txt

# Install Playwright browser binaries
playwright install chromium


2. API CONFIGURATION
--------------------------------------------------------------------------------
PEEK requires an inference API key (Groq Cloud).

1. Copy .env.example to .env:
   copy .env.example .env

2. Open .env in any text editor and paste your Groq API key:
   GROQ_API_KEY=gsk_your_groq_api_key_here

Get your free API key at: https://console.groq.com/keys


3. EXECUTION COMMANDS
--------------------------------------------------------------------------------

A. Windows One-Click Menu Launcher:
   .\run.bat

B. Interactive Terminal Shell:
   python cli.py

   Launches the interactive "peek > " prompt for multi-turn browsing sessions.
   Type 'exit' or 'quit' when finished.

C. Direct One-Liner Search Queries:
   # Headless execution (default, fast):
   python cli.py --goal "Who founded Wikipedia and when?" -u https://en.wikipedia.org

   # Headed execution (watch browser interact in real-time):
   python cli.py --goal "Search for Alan Turing" -u https://en.wikipedia.org --headed

D. Web Cockpit (Streamlit Dashboard):
   python -m streamlit run ui/dashboard.py
   (Opens http://localhost:8501 automatically in your browser)

E. Evaluation Benchmark Suite:
   python eval/runner.py --headless
   (Runs full 6-task WebArena mini-benchmark suite with structured metrics)

5. COMMON TROUBLESHOOTING TIPS
--------------------------------------------------------------------------------

• PowerShell Execution Policy Error:
  If running 'Activate.ps1' produces: "cannot be loaded because running scripts is disabled..."
  Solution: Run in PowerShell:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

• Playwright Executable Missing:
  If Chromium fails to launch: "Executable doesn't exist..."
  Solution:
  playwright install chromium

• LLM Rate Limits (HTTP 429):
  Groq free tier has an 8,000 Tokens-Per-Minute (TPM) limit. PEEK includes DOM token
  pruning and exponential backoff to handle rate limits automatically. If you run
  several heavy queries back-to-back, pause 10-15 seconds before the next query.

• Logs & Telemetry Audit:
  Full telemetry traces are saved silently to:
  logs/agent_run_<timestamp>.jsonl
